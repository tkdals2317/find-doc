# 동의어 사전

질문을 키워드로 바꿀 때와 Figma 인덱싱 키워드로 함께 쓴다.
형식: `- 대표어: 동의어, 동의어` (한 줄에 하나). 팀에서 PR 로 계속 보탠다.

- 지원서: 입사지원서, 입사지원, 지원양식, 지원항목, application
- 공고: 채용공고, 모집공고, 공고문, job posting
- 전형: 채용전형, 전형단계, 서류전형, 프로세스
- 면접: 인터뷰, 면접관, 면접일정, interview
- 역량검사: 인적성, 적성검사, 역량평가
- 평가: 평가표, 채점, 심사, 평가항목
- 합격: 합격자, 합격발표, 결과발표, 불합격
- 지원자: 후보자, 응시자, candidate
- 기획서: 기획, 화면설계, 스토리보드, 정책서, 요구사항, spec
- 시안: 디자인, 디자인시안, UI
- 관리자: 어드민, admin, 백오피스
- 알림: 메일, 문자, 알림톡, 노티
